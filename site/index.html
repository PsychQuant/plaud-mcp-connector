The gap this fills

Plaud shipped an official MCP server on 6 August 2026. It is good, and this plugin runs it unmodified — this is not a replacement, it contains it. But its surface is deliberately narrow.

Install

Requires Node.js 20+ and a Plaud account with Cloud Sync enabled.

/plugin marketplace add PsychQuant/plaud-mcp-connector
/plugin install plaud-mcp-connector@plaud-mcp-connector

Then authorise once — ask Claude to “log me into Plaud”. Both commands above were run end to end against a clean install; they are tested, not assumed.

npm install -g @plaud-ai/cli
plaud login

With the CLI installed, indexing writes transcripts straight to disk instead of reading every one through the model context — the difference between a few minutes and a very expensive afternoon on a library of hundreds. The CLI keeps its own login, separate from the MCP's.

# macOS only — upload drives Safari
brew install ffmpeg

Subtitle export needs nothing extra: it reads the local cache. Upload is browser automation against the Plaud web app and works on macOS only.

When not to install this

  • You only have a handful of recordings. The official plugin's name search is enough; indexing buys you nothing.
  • You want upload but aren't on macOS. The upload path drives Safari through AppleScript. There is no Linux or Windows equivalent, and none is planned.
  • You want a hosted service. Everything here runs on your machine, against your own account.

Limits, stated plainly

  • Search covers what you indexed. A recording made after your last index run is not searchable. The tool reports the covered range instead of answering “not found”.
  • Completeness is tracked, not assumed. A recording whose fetch was cut short is marked incomplete, re-fetched next run, and flagged in results. This exists because v0.1.0 silently kept only each transcript's first page and reported “no match” for words that were spoken.
  • Upload is browser automation, not an API. It works today and will break the day Plaud redesigns its import dialog.
  • Proofreading has no accuracy figure. Without a ground-truth transcript there is nothing to measure against. You will notice you can find things; nobody can give you a number.

Your recordings stay yours. Transcripts are cached on your own machine and are never committed, uploaded, or sent anywhere except to the model answering your question. Credentials live in your OAuth token store or the macOS Keychain.
